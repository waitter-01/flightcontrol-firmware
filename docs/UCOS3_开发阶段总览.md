# μC/OS-III 飞控开发阶段总览

## 当前结论

截至 2026-09-01，μC/OS-III 目标工程已经完成可在现有资料条件下离线实现的七个软件阶段，
并通过 Xilinx SDK 2019.1 ARM GNU Debug 构建。工程仍未经过 JTAG、FPGA、传感器、执行机构、
动力系统或飞行验证，不能作为可飞版本使用。

## 阶段与提交边界

| 阶段 | 主要结果 | 实物依赖 |
|---|---|---|
| 环境模板 | μC/OS-III 1.44 BSP、恢复脚本、最小应用 | 无 |
| 基础层 | 时间、日志、健康监测、安全门、看门狗锁定接口 | 无 |
| 硬件底座 | HDF 资源表、统一中断、只读 GPIO | 原理图确认 |
| 独立驱动 | IIC、PS/PL UART、CAN、AD7606、SPI 能力边界 | 总线与设备验证 |
| 数据通路 | 时间戳数据模型、SBUS、GF404 分帧、最新快照 | 协议与字节序确认 |
| 地面站 | MAVLink 心跳/状态、参数 RAM 服务、QGC 方案 | 串口联机 |
| 飞控核心 | 四元数姿态估计、PID、六旋翼控制分配 | SIL/HIL 与参数整定 |
| 输出仲裁 | 候选/实际命令隔离、拒绝统计、危险操作锁定 | 后端专项审核 |

## 已完成的离线验证

- μC/OS-III 危险硬件调用扫描通过；
- BSP 生成和构建通过；
- 所有新增 C 源码使用 ARM GNU `-Wall -Wextra` 编译；
- 应用链接通过；
- 最终 ELF：`text 123224 B`、`data 2708 B`、`bss 42480 B`；
- 主要公开函数和任务入口使用中文 Doxygen 注释；
- 每个阶段保留独立 Git 提交，可按功能点回退。

## 不能在离线阶段宣称完成的事项

以下内容缺少实物或正式协议资料，不能靠猜测实现：

1. HDF 中 GPIO、PWM、PL UART、AD7606 与实际针脚/负载的完整映射；
2. PWM 自定义 IP 的权威寄存器协议、电机编号、有效电平和安全零值；
3. GF404 载荷字段的端序、缩放和结构版本；
4. CAN 设备协议、位时序和收发器终端；
5. QGroundControl 实际链路端口和带宽预算；
6. IMU 标定、机架惯量、执行机构动态和 PID 参数；
7. 解锁条件、人工急停、失控保护和硬件看门狗复位链；
8. QSPI 分区、掉电恢复和写入寿命。

这些项目将在统一上机测试中逐项确认，并以新的小提交补充具体后端。任何后端提交都不得同时
开放解锁状态，必须先证明零输出和故障锁定可靠。
