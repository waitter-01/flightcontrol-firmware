# FlightControl 统一上机测试计划

## 测试原则

测试严格按风险递增推进。任一级失败都停止后续测试，保存日志并回退到最近通过的 Git
提交。首次测试不得连接螺旋桨，历史 BOOT.BIN 不得直接烧写，QSPI 不得擦写。

## 第 0 级：测试前审查

- 核对芯片丝印、原理图、电源树、复位、启动模式和 JTAG 电压；
- 建立“接口—针脚—IP—地址—驱动—负载—有效电平”签字版表格；
- 确认所有电机、螺旋桨、舵机、继电器和可控配电负载断开；
- 准备限流电源、急停/断电手段、示波器或逻辑分析仪；
- 记录待测提交哈希、ELF 哈希、bitstream 哈希和工具版本。

通过条件：硬件资源表无未知危险输出，现场具备立即断电能力。

## 第 1 级：JTAG 与安全启动

1. 只执行 `connect` 和 `targets`，确认 Zynq 与 ARM0；
2. 下载参考 bitstream 和当前 μC/OS-III ELF，不写 QSPI；
3. 停在 `main()`，单步进入 Micrium 启动；
4. 确认控制台输出平台初始化和输出锁定；
5. 观察 5 分钟，无异常复位、无危险 GPIO/PWM 动作；
6. 执行健康心跳故障注入，确认进入 `FAULT_LOCKED`。

通过条件：任务持续运行、故障可锁存、所有实际输出保持安全零状态。

## 第 2 级：只读输入和总线

- 逐个启用一个 GPIO 输入、AD7606、IIC、PL UART、PS UART 或 CAN；
- 每次只增加一个设备并形成独立提交；
- 记录空闲值、边界值、超时、拔插、短时干扰和恢复行为；
- 检查任务周期、栈余量、错误计数和 CPU 占用。

通过条件：设备失败不会阻塞健康任务，错误能上报且不影响其他总线。

## 第 3 级：传感器和遥控链路

- 用协议手册逐字段确认 GF404 端序、缩放、单位和校验；
- 对比静止、已知姿态和已知运动下的 IMU/GNSS 数据；
- 校验 SBUS 18 通道范围、帧丢失和 failsafe；
- 模拟数据停止，确认过期样本不会进入控制链；
- 保存原始字节流用于离线回放。

通过条件：时间戳单调、单位和坐标系正确、失控和过期均触发拒绝。

## 第 4 级：QGroundControl

- 使用独立 MAVLink 链路连接 QGroundControl；
- 验证 HEARTBEAT、SYS_STATUS、断线重连和带宽；
- 验证参数列举、读取、RAM 修改和范围拒绝；
- 确认解锁命令不能改变当前锁定状态；
- 进行链路洪泛测试，确认控制任务不被阻塞。

通过条件：地面站稳定识别，错误命令和链路异常不能解除机载安全门。

## 第 5 级：SIL/HIL 与控制方向

- 用记录数据回放姿态估计并检查四元数归一化和偏航漂移；
- 验证 PID 阶跃、饱和、反积分饱和和模式切换复位；
- 对六个电机逐轴检查滚转、俯仰和偏航混控符号；
- HIL 注入传感器丢失、时间跳变、遥控失控和任务超时；
- 输出只观察仲裁器候选值，不绑定硬件后端。

通过条件：所有故障场景输出候选值归零或被仲裁器拒绝。

## 第 6 级：无桨执行机构

只有前五级全部通过后，才能根据已确认的寄存器协议实现 PWM/CAN ESC 硬件后端。先用逻辑
分析仪或示波器验证零输出、频率、脉宽、编号和故障恢复，再连接无桨电机并限流供电。

通过条件：上电、复位、JTAG 暂停、链路断开、任务超时和急停时均回到安全输出。

## 第 7 级：系留与飞行

依次进行单电机台架、整机无桨、整机有桨固定、低推力系留、低高度悬停和扩大包线。每一步
都需要独立测试记录、风险复核和明确放行，不因上一阶段通过而自动授权下一阶段。
