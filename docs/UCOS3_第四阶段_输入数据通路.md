# μC/OS-III 第四阶段：输入数据通路

## 阶段结果

本阶段建立算法可以稳定依赖的数据契约：

- 统一微秒时间戳、序号、有效/校准/失控/过期标志；
- IMU 采用 FRD 机体系和 SI 单位；
- GNSS 使用 WGS84 整数经纬度、毫米高度和 NED 速度；
- 遥控通道归一化为 `[-1, 1]`；
- 固定内存序列锁保存 IMU、GNSS、遥控最新快照；
- SBUS 25 字节帧解析；
- GF404 `55 AA 长度 ID 数据 XOR` 有界分帧。

旧 GF404 结构直接 `memcpy` 依赖编译器结构对齐和设备字节序。本阶段只完成严格分帧，具体
载荷字段必须依据 GF404 协议手册逐字段解码，不能继续复制未知布局结构。

输入仓库不使用消息堆积，控制器始终读取最新快照。每个消费者必须根据时间戳自行拒绝过期
数据；数据存在不等于数据有效。
