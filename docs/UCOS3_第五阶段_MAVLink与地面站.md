# μC/OS-III 第五阶段：MAVLink 与地面站

## 地面站决策

项目不单独开发完整地面站，采用 QGroundControl。机载端只实现标准 MAVLink 2 服务和确有
必要的飞控扩展，避免重复开发地图、参数、任务规划、日志和固件升级等成熟功能。

## 本阶段实现

- 复用原工程已有的 MAVLink C 生成代码；
- 增加有界流式接收端和解析错误统计；
- 增加六旋翼 `HEARTBEAT`，故障锁定时上报 `MAV_STATE_CRITICAL`；
- 增加 `SYS_STATUS` 构建接口，未知电压、电流和剩余电量使用 MAVLink 约定值；
- 增加 64 项固定容量参数仓库，支持类型、范围、只读和重复名称检查；
- 参数持久化固定返回安全锁定，不会写入 QSPI。

## 后续上机验收

1. 选择独立 MAVLink UART，不与 SBUS 或调试控制台争用；
2. QGroundControl 能稳定识别六旋翼心跳；
3. 断线重连后系统编号和组件编号保持稳定；
4. 参数列表、读取和 RAM 修改正确；
5. 地面站发来的解锁命令不能绕过机载安全状态机；
6. 链路拥塞不得阻塞姿态控制任务。

任务协议、日志下载、FTP 和固件升级应在基础链路通过实测后按标准 MAVLink 服务增量启用。
