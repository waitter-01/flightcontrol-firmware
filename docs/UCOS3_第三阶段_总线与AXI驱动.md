# μC/OS-III 第三阶段：总线与自定义 AXI 驱动

## 阶段结果

本阶段把旧工程中可确认的底层访问提取为独立驱动：

- AXI IIC 主机初始化和寄存器读取事务；
- Micrium PS UART 配置和发送适配；
- 两个 AD7606 自定义 AXI IP 的只读寄存器访问；
- 通用驱动统计和更细的错误码；
- 通用 SPI 能力探测接口。

所有驱动只保存固定大小实例，不使用动态内存。它们没有接入启动流程，因此构建此阶段不会
自动访问尚未确认的传感器、CAN 收发器或 PL 外设。

## 当前硬件限制

当前 HDF 没有提供普通 PS/PL SPI 控制器，只存在 PS QSPI。QSPI 连接启动 Flash，不能在
没有原理图和启动介质确认的情况下复用为传感器总线。因此 `fc_spi_transfer()` 明确返回
`FC_STATUS_NOT_SUPPORTED`，而不是伪造一个无法工作的实现。

PS UART0 当前同时承担模板控制台，而旧工程将其配置为 420000、8E2 接收机链路。两种用途
不能同时启用。后续通信服务必须在启动配置中明确选择 UART0 所有者。

## 旧实现中已消除的问题

- 不再使用无限 `while` 等待 CAN/串口状态；
- 不在每次 UART 读取时重新初始化控制器；
- 不把 IIC 从设备协议写进总线层；
- 不用 UART IP 的宏读取 AD7606 地址；
- 不把 QSPI Flash 当作普通 SPI 总线；
- 所有公开主要函数使用中文接口注释并返回统一错误码。
