# μC/OS-III 第六阶段：估计、控制与 SIL

## 阶段结果

- 姿态估计使用四元数陀螺积分和加速度重力校正；
- 采用 FRD 机体系到 NED 导航系的旋转约定；
- PID 使用测量值微分、输出限幅和反算抗积分饱和；
- 六旋翼控制分配按机头开始、顺时针每 60 度的编号约定；
- 相邻电机偏航旋向交替，混控饱和后统一归一化；
- 算法层不依赖 Xilinx、μC/OS 或硬件寄存器。

## 重要限制

当前姿态估计没有磁力计航向校正，偏航会随陀螺零偏漂移；也没有完成位置 EKF。它适合作为
首轮姿态环和 SIL 骨架，不应在参数整定、传感器标定、机架惯量和电机响应未知时直接飞行。

实机前必须确认电机编号、安装角、旋向、推力方向和执行机构协议。控制器输出仍不会直接到达
硬件，必须经过下一阶段的安全仲裁。
